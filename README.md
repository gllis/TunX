# TunX

TunX 是一款 macOS 菜单栏应用，用于可视化管理 SSH 本地转发（`-L`）、远程转发（`-R`）以及动态 SOCKS 代理（`-D`）隧道。

## 功能

- **可视化隧道管理**：增删改查 SSH 隧道，支持多条转发规则。
- **多种认证方式**：支持密码与 SSH 私钥（含密钥口令）。
- **快速启停**：通过状态栏图标一键开启或停止隧道。
- **自动重连**：隧道异常断开后可按设定间隔自动重连。
- **实时日志**：查看每条隧道的 ssh 输出与运行状态。
- **命令预览**：自动生成并预览对应的 `ssh` 命令。

## 运行环境

- macOS 14.0+
- Xcode 26.0+（SwiftData、SwiftUI）
- 系统需已安装 `/usr/bin/ssh`

## 使用方式

1. 从 Xcode 打开 `TunX.xcodeproj` 并运行。
2. 启动后应用仅出现在系统状态栏（不显示 Dock 图标）。
3. 点击状态栏图标：
   - **左键**：展开隧道列表与「打开 TunX」快速操作面板。
   - **右键**：显示上下文菜单，包含「打开 TunX」与「退出」。
4. 在主窗口中配置隧道、转发规则并启动连接。

## 交互说明

- 应用启动后不显示 Dock 图标，仅出现在状态栏。
- 打开主窗口时会临时显示 Dock 图标，便于窗口管理；关闭主窗口后 Dock 图标自动隐藏，应用继续在后台运行。
- 为避免误操作关闭后台隧道，退出入口仅放在状态栏图标的右键菜单中，左键弹出面板上不再提供退出按钮。
